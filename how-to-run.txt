========================================================================
             STANDALONE PDF BANK STATEMENT EXTRACTOR: HOW TO RUN
========================================================================

Choose your command line shell below to copy, paste, and run the extractor.

------------------------------------------------------------------------
OPTION A: WINDOWS POWERSHELL (RECOMMENDED)
------------------------------------------------------------------------
Copy and paste the following block into your PowerShell window:

# 1. Navigate to the standalone extractor directory
cd "e:\Main Projects\Loan_Approval\pdf_extractor"

# 2. Activate the virtual environment
.\venv\Scripts\Activate.ps1

# 3. Run the extractor script
python extractor.py


------------------------------------------------------------------------
OPTION B: WINDOWS COMMAND PROMPT (CMD)
------------------------------------------------------------------------
Copy and paste the following block into your standard Command Prompt window:

:: 1. Navigate to the standalone extractor directory
cd /d "e:\Main Projects\Loan_Approval\pdf_extractor"

:: 2. Activate the virtual environment
call .\venv\Scripts\activate.bat

:: 3. Run the extractor script
python extractor.py


------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------
* Make sure you place your PDF statements inside the "uploads" folder 
  (e.g., e:\Main Projects\Loan_Approval\pdf_extractor\uploads\) before 
  running the script.
* Extracted statements will be saved in CSV, Excel (XLSX), JSON, and 
  formatted Text formats inside the "output" folder.
